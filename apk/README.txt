Nvidia Vision Chatbot - Debug Builds
====================================

Files available:
1. nvidia-vision-chatbot.apk (Direct Android Application Package - 23MB)
2. nvidia-vision-chatbot.zip (Same binary packaged as .zip in case of browser/firewall APK download restrictions)
3. /app-debug.apk (Root APK)
4. /app-debug.zip (Root ZIP)

How to install on Android device:
1. Download nvidia-vision-chatbot.apk (or download the .zip and rename the extension to .apk).
2. Transfer or open the .apk on your Android phone or tablet.
3. If prompted, enable "Install unknown apps" in Settings for your browser or file manager.
4. Tap Install to run the app.
